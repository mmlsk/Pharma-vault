# 💊 Pharma-vault

Krytyczna, medycznie zorientowana analiza materiału **„Biohacking Bible – A Neuropharmacology Encyclopedia” (wyd. 14)** — kompilacji o lekach psychotropowych, nootropikach, peptydach i substancjach eksperymentalnych.

> ⚠️ **Zastrzeżenie:** repozytorium ma charakter wyłącznie edukacyjny (nauka farmakologii klinicznej). Nie zawiera zaleceń dawkowania i nie stanowi porady medycznej.

## 📂 Struktura

| Plik | Zawartość |
|---|---|
| [`notes/01-przeglad-krytyczny.md`](notes/01-przeglad-krytyczny.md) | Mapa zawartości PDF, problemy metodologiczne, czerwone flagi (IMAO, tianeptyna, research chemicals, genetyka „methylation”), filtr krytyczny |
| [`notes/02-tabela-selekcyjna.md`](notes/02-tabela-selekcyjna.md) | Tabela oceny ~70 kluczowych substancji/grup z legendą 🟢🟡🟠🔴⚫ |
| [`notes/03-zakres-pominiec.md`](notes/03-zakres-pominiec.md) | Szacunek pominiętych pozycji i ich kategorie |
| [`notes/04-pelna-tabela.md`](notes/04-pelna-tabela.md) | Pełna encyklopedia w 7 blokach: antydepresanty, stymulanty/nootropiki, research chemicals, peptydy, suplementy, psychodeliki, dysocjanty/kannabinoidy |
