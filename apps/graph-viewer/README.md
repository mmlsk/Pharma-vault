# 🕸️ Graph viewer

Samodzielny plik HTML (Canvas, bez zależności) z interaktywnym grafem 40 węzłów: klastry, ścieżki, koncepcje i hubsy bezpieczeństwa vaultu. Otwórz `index.html` bezpośrednio w przeglądarce.

Status: statyczny (dane wbudowane w plik). Docelowo — generowanie węzłów z `data/processed/substances.json` (zob. [ADR-0001](../../docs/adr/0001-canonical-source-of-truth.md)).
